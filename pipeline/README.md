# Пайплайн Silvius

Этот каталог содержит агентный API и алгоритмы анализа организационных документов. Он запускается вместе с Silvius из корня репозитория командой `npm start`; отдельного интерфейса у пайплайна больше нет. Пользовательский интерфейс находится в `../frontend_silvius/`, а API доступен через защищённый префикс `/api/hectra/`.

Шесть ролей (`routing`, `extraction`, `comparison`, `crosscheck`, `judge`, `synthesis`) и общий промпт находятся в `prompts/system/`. Контракты результатов — в `shared/contracts.js`. Серверные стадии, извлечение и хранение — в `server/`. Исходные файлы сохраняются в `../data/pipeline/` по умолчанию. Ключ указывается в `server-config.local.cjs`, который исключён из Git. Порядок запуска и пользовательский сценарий описаны в [корневом README](../README.md).

`INTEGRATION.md` — исходная инструкция поставки пайплайна. Она описывает прежний отдельный интерфейс и отдельный сервер; для текущего проекта используйте корневой README и `../server/app.js`.
