# Silvius — веб-интерфейс

Новый фронтенд для агента анализа организационной структуры и функционала. Он написан с нуля на HTML, CSS и JavaScript, без сборщика и внешних библиотек.

## Запуск

Используйте [инструкцию в корневом README](../README.md): `npm ci`, затем `npm start` из корня репозитория. Express обслуживает страницы и API с `http://localhost:3000`. Обычный статический сервер не обеспечивает работу входа и закрытого рабочего пространства.

Регистрация, вход, загрузка документов, история сравнений и страница результатов работают через защищённый API `/api/hectra/`. Системные промпты поставляются вместе с проектом; для реальных вызовов модели нужен серверный API-ключ, как описано в корневом README.

## Логотип Silvius

В `assets/` лежат переданные версии логотипа Silvius. Тема автоматически переключает два файла:

- `silvius-logo-light.svg` — вариант на светлом фоне;
- `silvius-logo-dark.svg` — вариант на тёмном фоне.

`js/site.js` выбирает файл по текущей теме. Если файл недоступен, остаётся буквенный резервный знак `S`. Размер области логотипа задаётся классом `.brand-mark` в `css/styles.css`.

Лендинг использует входные анимации, последовательность подсветки схемы и появление разделов при прокрутке. При системной настройке уменьшения движения анимации выключаются.

## Визуальный референс и атрибуция

Цвета и двухстрочная шапка вдохновлены [сайтом Казахтелекома](https://telecom.kz/ru). Локальный файл `assets/kazakhtelecom-logo.webp` получен из [Logo KT.svg на Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Logo_KT.svg), автор Назерке Жантуарова, лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Файл не утверждает официальный статус Silvius. Перед публичной публикацией логотип партнёра следует сверить с предоставленными бренд-материалами.

`js/site.js` получает текущего пользователя от сервера и обрабатывает выход, а `js/auth.js` отправляет существующую форму входа и регистрации в API. Секреты и результаты анализа в браузере не хранятся.
