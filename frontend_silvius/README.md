# Silvius — интерфейсный прототип

Новый фронтенд для агента анализа организационной структуры и функционала. Он написан с нуля на HTML, CSS и JavaScript, без сборщика и внешних библиотек.

## Посмотреть локально

Из каталога `frontend_silvius` запустите любой статический сервер, например:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8000/`. Дополнительные страницы: `workspace.html` и `auth.html`.

Это именно фронтенд-этап: файлы выбираются только в текущей вкладке и не отправляются; анализ, регистрация, вход и история пока не подключены. Отключённые действия и пометки на страницах отражают это явно.

## Логотип Silvius

В `assets/` лежат переданные версии логотипа Silvius. Тема автоматически переключает два файла:

- `silvius-logo-light.svg` — вариант на светлом фоне;
- `silvius-logo-dark.svg` — вариант на тёмном фоне.

`js/site.js` выбирает файл по текущей теме. Если файл недоступен, остаётся буквенный резервный знак `S`. Размер области логотипа задаётся классом `.brand-mark` в `css/styles.css`.

Лендинг использует входные анимации, последовательность подсветки схемы и появление разделов при прокрутке. При системной настройке уменьшения движения анимации выключаются.

Локальный файл `assets/kazakhtelecom-logo.webp` получен из [Logo KT.svg на Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Logo_KT.svg), автор Назерке Жантуарова, лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Файл не утверждает официальный статус Silvius. Перед публичной публикацией логотип партнёра следует сверить с предоставленными бренд-материалами.

## Следующий этап

Сервер должен подключить сессию к `window.SilviusHeader.setUser({ name })` или `clearUser()`, обработать событие `silvius:logout-request` и заменить статические состояния страниц на API-запросы. Секреты и результаты анализа в браузере не хранятся.
